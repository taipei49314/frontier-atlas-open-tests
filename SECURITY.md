# Security policy

Do not disclose a suspected vulnerability in a public issue, pull request,
discussion, commit, or test packet.

Use GitHub's private vulnerability reporting form for this repository:

https://github.com/taipei49314/frontier-atlas-open-tests/security/advisories/new

Include the affected commit, impact, prerequisites, a minimal safe reproducer,
and any known mitigation. Do not include real credentials, private user data,
hidden labels, sealed cases, or unrelated repository contents.

Only the current `main` branch is in scope. This public verifier has no hosted
service and no provider integration, so reports about private product or
authority components cannot be validated through this repository.
